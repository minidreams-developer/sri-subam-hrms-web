# Face Capture API Contract

## Frontend flow

```text
Open camera
  ↓
Capture webcam frame automatically
  ↓
Detect face and generate numeric embedding
  ↓
Send embedding to backend
  ↓
Backend finds matching person
  ↓
Frontend displays returned person
```

## Endpoint

The frontend currently calls:

```http
POST /api/face/embedding
Content-Type: application/json
```

## Request payload

The production payload should contain a numeric face embedding:

```json
{
  "embedding": [0.1234, -0.2451, 0.9087]
}
```

The embedding should normally contain the fixed number of values required by
the selected face-recognition model. Do not send the webcam image as the
embedding in production.

## Successful response

Recommended response when a person is matched:

```json
{
  "success": true,
  "matched": true,
  "person": {
    "id": "person-id",
    "name": "Person Name",
    "employeeCode": "EMP001",
    "role": "Employee"
  },
  "confidence": 0.94
}
```

## No match response

```json
{
  "success": true,
  "matched": false,
  "person": null,
  "message": "No matching person found"
}
```

## Error response

```json
{
  "success": false,
  "message": "Face service unavailable"
}
```

## Backend responsibilities

1. Validate that `embedding` exists and contains numeric values.
2. Compare it with stored person embeddings.
3. Apply a model-appropriate similarity threshold.
4. Return the matched person only when the threshold is satisfied.
5. Avoid returning stored face embeddings in the response.

## Frontend integration note

The current test component uses a temporary webcam-image placeholder. Replace
that placeholder with the numeric descriptor generated by the face-recognition
model before connecting this endpoint in production.
